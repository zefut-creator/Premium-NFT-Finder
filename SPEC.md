# SayPlugin — техническое задание v1.3

## Цель
Создать модульную платформу для AyuGram Android с единым центром управления, личной памятью, обработкой текста, инструментами и безопасной автоматизацией. Все модули должны иметь независимые настройки и не выполнять скрытых действий.

## Платформа и ограничения
- Целевая платформа: AyuGram Android на совместимой базе exteraGram.
- SDK baseline: 1.4.4.3; app baseline: 12.5.1+.
- Python 3.11 внутри plugin runtime.
- Использовать публичные API SDK там, где это возможно.
- Любая функция, зависящая от внутренних классов Android-клиента, считается экспериментальной до теста на конкретной сборке.
- Данные архива и настроек хранятся локально в настройках плагина.
- Никакого скрытого чтения приватных чатов, выгрузки списков участников, фоновой массовой рассылки или автоматической отправки.
- Преобразования выполняются только над исходящим текстом пользователя до отправки; команды не должны запускать цепочки отправки.

## Архитектура
1. **Core / Dashboard** — единый вход, регистрация модулей, состояние и диагностика.
2. **Appearance Engine** — настройки панели SayPlugin, применение палитры через Theme.setColor и нативные фильтры списка AyuGram; внутренние API требуют проверки на конкретной сборке.
3. **Message Engine** — сокращения, шаблоны, форматирование и преобразование исходящего текста.
4. **Memory Engine** — архив только явно выбранных сообщений, поиск, лимиты и очистка.
5. **Automation Engine** — прозрачные пользовательские триггеры и текстовые макросы; без автоспама и самостоятельной рассылки.
6. **Search Engine** — поиск по личному архиву и выбранному пользователем содержимому.
7. **Utility Engine** — дата/время, счётчики, очистка и форматирование текста.
8. **Lab Engine** — диагностика, тесты совместимости и экспериментальные функции с отдельным включением.

## Реализация 0.5.1
- Добавлена экспериментальная интеграция с родными вкладками списка AyuGram.
- Категории: личные диалоги (контакты и не-контакты, без ботов), группы, каналы и боты.
- Категории строятся на встроенном MessagesController.DialogFilter и фильтруют штатный список диалогов.
- Счётчики рассчитываются как сумма unread_count подходящих диалогов, а не количество чатов.
- Вкладки локальные для клиента, не создают серверные фильтры и не передают содержимое диалогов наружу.
- После добавления каждого фильтра вызывается MessagesController.updateFilterDialogs, который заполняет DialogFilter.dialogs — источник данных для штатного списка.
- Интеграция использует внутренние классы DialogsActivity и MessagesController и остаётся экспериментальной до проверки на AyuGram 13.1.1.
- Цветовая палитра применяет значения штатным Theme.setColor и сохраняет текущую тему; выключение сбрасывает установленные значения через useDefault.
- Нестабильный перехват Theme.getColor удалён.
- Перехват Theme.getColor удалён как нестабильный.

## Семь направлений развития
### 1. Интеллект и память
- заметки и факты, которые пользователь сохраняет сам;
- краткие сводки выбранных сообщений;
- поиск по архиву, теги и коллекции;
- избранное и связанные записи.

### 2. Автоматизация
- конструктор макросов;
- условия и действия с предварительным просмотром;
- профили для разных чатов;
- напоминания и подтверждаемые отложенные действия;
- журнал запусков и глобальная пауза.

### 3. Работа с сообщениями
- папки сниппетов и шаблонов;
- форматирование и редактор;
- сравнение черновиков и поиск дублей;
- переводчик при явной настройке провайдера.

### 4. Поиск и архив
- поиск по словам, дате и тегам;
- коллекции и закреплённые записи;
- экспорт/импорт;
- очистка дубликатов.

### 5. Инструменты и утилиты
- калькулятор, дата/время, счётчики;
- форматирование, QR и кодирование/декодирование текста при наличии API;
- локальные инструменты без передачи содержимого сторонним сервисам по умолчанию.

### 6. Интерфейс и персонализация
- компактная панель, избранные модули и сортировка;
- профили внешнего вида панели;
- экспериментальная смена нескольких цветовых ключей через Theme.getColor, выключенная по умолчанию и требующая проверки на каждой сборке;
- полноценные темы, шрифты, иконки, фоновые изображения и профили чатов — только после проверки API AyuGram;
- никакого рискованного перехвата внутренних UI-классов без проверки.

### 7. Лаборатория
- экспериментальные виджеты;
- диагностика совместимости;
- самопроверка и просмотр логов;
- локальные пользовательские макросы.

## Критерии качества
- Каждый модуль можно отключить независимо.
- Функция не считается завершённой до проверки на конкретной сборке AyuGram.
- Ошибки обрабатываются на границах модулей и пишутся в лог.
- Хуки должны быть короткими.
- Обновления не должны терять пользовательские данные.
- Каталог содержит фактические SHA-256 и размер файла.
