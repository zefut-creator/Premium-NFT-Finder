# SayPlugin — техническое задание (v1)

## Цель
Создать модульную платформу-помощник для AyuGram Android. Все возможности доступны из одного главного меню, разделены на независимые модули и могут включаться отдельно.

## Совместимость и ограничения
- Целевая платформа: AyuGram Android на совместимой базе exteraGram.
- SDK baseline: 1.4.4.3; app baseline: 12.5.1+.
- Язык: Python 3.11 внутри plugin runtime.
- UI — через публичные UI helpers SDK.
- Никакого скрытого чтения приватных чатов, выгрузки аккаунтов или фоновой массовой рассылки.
- Данные хранятся локально в настройках плагина.
- Автоматические действия прозрачны, отключаемы и ограничены текущим действием пользователя.

## Архитектура
1. Core: metadata, lifecycle, settings, dashboard, module registry.
2. Message Engine: outgoing-message hook, shortcuts, text transforms, templates.
3. Memory Engine: user-selected saved messages, notes, personal archive.
4. Search Engine: поиск по локально доступному и выбранному пользователем содержимому.
5. Automation Engine: пользовательские макросы и явные триггеры без бесконтрольных циклов.
6. Utility Engine: дата/время, счётчики, форматирование и локальные инструменты.
7. UI Engine: единая панель, страницы модулей, статус и настройки.
8. Lab Engine: экспериментальные модули с отдельными переключателями.

## Первая реализация: 0.1.0
- Пункт SayPlugin в главном меню.
- Страница настроек с включением автосокращений и редактором сокращений.
- Автозамена сокращений в исходящем сообщении. Формат: одна строка ` ;ключ=текст ` (без пробелов вокруг ключа).
- Переменные `{date}` и `{time}`.
- Команды: `.sayhelp`, `.saydate`, `.saytime`, `.sayupper текст`, `.saylower текст`, `.saylen текст`.
- Сохранение отдельного текстового сообщения через его контекстное меню.
- Личный архив до 100 записей, просмотр из главного меню.
- Разделы панели: архив, сокращения, команды, статус модулей.

## Планируемые модули
### Интеллект и память
- заметки и факты, которые пользователь сохраняет сам;
- краткие сводки из выбранных сообщений;
- поиск по личному архиву;
- коллекции тем и связанные записи.

### Автоматизация
- конструктор макросов;
- цепочки «условие → действие»;
- профили для разных чатов;
- напоминания и подтверждаемые отложенные действия;
- история запусков и глобальная пауза.

### Работа с сообщениями
- шаблоны и папки сниппетов;
- форматирование;
- сравнение черновиков и поиск дублей;
- редактор текста;
- переводчик при явной настройке провайдера.

### Поиск и архив
- поиск по словам, дате и тегам;
- коллекции и закреплённые записи;
- экспорт/импорт;
- очистка дубликатов.

### Инструменты и утилиты
- калькулятор, дата/время, счётчики слов и символов;
- генератор случайных значений для обычных личных задач;
- QR-коды и кодирование/декодирование текста при наличии API.

### Интерфейс и персонализация
- компактная панель;
- избранные модули и сортировка;
- темы и профили чатов, если это поддерживается SDK;
- горячие действия только через доступные API AyuGram.

### Лаборатория
- экспериментальные виджеты;
- диагностика совместимости;
- самопроверка плагина и просмотр логов;
- локальные пользовательские макросы.

## Критерии качества
- Каждый модуль можно отключить независимо.
- Функция не считается завершённой до проверки на конкретной сборке AyuGram.
- Ошибки обрабатываются на границах модулей и пишутся в лог.
- Хуки должны быть короткими; тяжёлые задачи уходят в фоновую очередь.
- Обновления не должны терять пользовательские данные.
- Индекс каталога всегда содержит фактические SHA-256 и размер файла.
