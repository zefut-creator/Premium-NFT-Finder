# Premium-NFT-Finder

Telegram-бот для поиска публичных сообщений, в которых автор сам явно сообщает о наличии у него Telegram Premium или NFT-подарков.

## Что делает бот
- Работает только в группах, где бот добавлен и мониторинг явно включён администратором группы командой `/watch`.
- Ищет узкие формулировки самостоятельного упоминания Premium/NFT.
- Сохраняет текст совпавшего сообщения, username (если публичен), группу, дату и ссылку на сообщение (если группа публичная).
- Присылает владельцу уведомление о новом совпадении.
- Не выгружает список участников, не определяет скрытый Premium/NFT, не собирает контакты и не отправляет людям личные сообщения.

## Важно: ограничения Telegram
Обычный Telegram-бот не может присоединиться к группе только по ссылке и прочитать её историю. Бота нужно добавить в группу. Мониторинг должен включить администратор этой группы. Для получения обычных сообщений в группе отключи Privacy Mode через @BotFather: /setprivacy → выбери бота → Disable. Если администратор группы не добавит бота и не включит мониторинг, сообщения из группы недоступны.

## Настройка
1. Node.js 18 или новее.
2. `npm install`
3. Переменные окружения:
   - `BOT_TOKEN` — обязательно, токен BotFather.
   - `ADMIN_ID` — обязательно, твой числовой Telegram user ID.
   - `DB_PATH` — необязательно, путь к JSON-файлу. По умолчанию `./data/scanner.json`.
4. Команда запуска: `npm start`.

## Команды
- В личном чате с ботом: `/start`, `/sources`, `/results`, `/clear`.
- В группе (только администратор группы): `/watch` — включить мониторинг; `/unwatch` — выключить.

## Хранение
Используется JSON-файл. Подключи постоянное хранилище на хостинге, иначе данные могут исчезнуть после пересоздания контейнера.

## Безопасность
Не публикуй BOT_TOKEN. Не отправляй API hash, коды входа или пароль двухэтапной проверки. Если токен раскрыт, перевыпусти его через BotFather. Не запускай один и тот же токен одновременно в нескольких экземплярах.
