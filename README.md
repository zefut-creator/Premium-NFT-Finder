# SayPlugin

**SayPlugin** — модульный центр инструментов и персонализации для AyuGram Android.

## Версия 0.5.0

### Вкладки списка чатов
- Плагин добавляет в родную панель фильтров AyuGram категории «Личка», «Чаты», «Каналы» и «Боты».
- Используются встроенные фильтры MessagesController.DialogFilter, а не отдельная имитация списка.
- Счётчик каждой категории рассчитывает сумму непрочитанных сообщений в подходящих диалогах.
- Категории добавляются только в память текущего клиента и не отправляются на сервер Telegram.
- Это экспериментальная интеграция с внутренними классами AyuGram; требуется проверка на версии 13.1.1. Если вкладки не появились или список работает некорректно, выключи «Вкладки списка чатов» в настройках плагина.

## Версия 0.4.0

### Исправления сокращений
- Исправлен разбор сокращений, если редактор сохраняет все записи одной строкой.
- Поддерживаются оба варианта: по одной записи на строку и подряд через `;ключ=текст`.
- Примеры: `;пр=Привет, как дела?`, `;спс=Спасибо!`, `;пж=Пожалуйста!`.
- Важно: текущая реализация подставляет сокращения перед отправкой сообщения, а не в момент набора.

### Валюты и конвертер
- `.валюты` — список поддерживаемых фиатных валют.
- `.валюта 2000 KZT RUB` — конвертация по справочному курсу.
- `.валюта тенге 2000 = рубли` — тот же запрос с русскими названиями.
- Фиатные курсы загружаются из open.er-api.com; BTC и GRAM — из CoinGecko.
- Сетевые запросы выполняются в отдельном потоке, чтобы не блокировать интерфейс.
- Расчёт ориентировочный: курс обменника, комиссии и спред могут отличаться.

Поддерживаются KZT, RUB, USD, UAH, EUR, GBP, CNY, TRY, BTC и GRAM. GRAM используется как актуальное обозначение Gram (бывший Toncoin) в CoinGecko.

## Возможности 0.3.0
- Главное меню и меню действий чата.
- Вложенные разделы: архив, текст, автоматизация, внешний вид, инструменты, лаборатория и диагностика.
- Личный архив только выбранных пользователем сообщений.
- Поиск по архиву через `.sayfind` и открытие через `.sayarchive`.
- Цветовая тема Telegram экспериментальная и выключена по умолчанию.
- Текстовые команды форматирования и пользовательские шаблоны.

## Установка репозитория

Добавь в AyuGram → Plugins → Repositories адрес ветки:

`https://github.com/zefut-creator/Premium-NFT-Finder/tree/sayplugin-v1`

Затем обнови список и установи **SayPlugin**. Если каталог не принимает ссылку на ветку, можно установить файл вручную из `plugins/sayplugin/sayplugin.plugin`.

## Совместимость и проверка

Плагин ориентирован на публичный SDK exteraGram 1.4.4.3 и baseline приложения 12.5.1+. Совместимость зависит от конкретной сборки AyuGram. На реальном устройстве ещё требуется проверка; сетевые курсы также зависят от доступности внешних API.
