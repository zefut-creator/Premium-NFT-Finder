# Premium-NFT-Finder

Telegram-бот-каталог для участников, которые **добровольно** сообщают о наличии Telegram Premium и NFT-подарков.

## Возможности
- Регистрация через `/start`.
- Самостоятельное указание Premium и NFT.
- Каталог только зарегистрированных участников.
- Реферальные ссылки и подсчёт приглашений.
- Просмотр и удаление собственного профиля.
- Административная статистика через `/stats`.

## Ограничения и приватность
Telegram Bot API не позволяет боту просканировать всех пользователей Telegram или достоверно получить скрытый список Premium/NFT. Статусы указываются самими участниками и не являются независимой проверкой. Бот не собирает чужие контакты, не рассылает сообщения и не извлекает скрытые данные.

## Запуск на хостинге
1. Установи Node.js 18 или новее.
2. Установи зависимости командой `npm install`.
3. Добавь переменную окружения `BOT_TOKEN` — токен от BotFather.
4. Необязательно: добавь `ADMIN_ID` — числовой Telegram ID администратора.
5. Команда запуска: `npm start`.

Бот использует long polling и при старте удаляет webhook, если он был установлен. Не запускай один и тот же токен одновременно на двух хостингах или в двух процессах: Telegram вернёт ошибку конфликта.

## Переменные окружения
- `BOT_TOKEN` — обязательно.
- `ADMIN_ID` — необязательно.
- `DB_PATH` — необязательно, путь к JSON-файлу базы. По умолчанию `./data/users.json`.

Для сохранения профилей после перезапуска подключи на хостинге постоянное хранилище и укажи `DB_PATH` внутри него. Без постоянного хранилища данные могут сбрасываться при пересоздании контейнера.

## Безопасность
Не публикуй токен бота в репозитории, сообщениях или скриншотах. Если токен случайно раскрыт, перевыпусти его через BotFather.
