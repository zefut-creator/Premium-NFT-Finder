# SayPlugin

**SayPlugin** — модульный набор инструментов для AyuGram Android. Проект развивается поэтапно: сначала стабильное ядро и рабочие базовые функции, затем независимые модули.

## Уже реализовано в 0.1.0
- Пункт **SayPlugin** в главном меню Telegram.
- Автоматические текстовые сокращения, настраиваемые в параметрах плагина.
- Переменные `{date}` и `{time}` в сокращениях.
- Команды `.sayhelp`, `.saydate`, `.saytime`, `.sayupper текст`, `.saylower текст`, `.saylen текст`.
- Личный архив: сохранить отдельное текстовое сообщение через контекстное меню и открыть его из SayPlugin.
- Статус модулей и просмотр сокращений.

## Установка репозитория
Добавь в AyuGram → Plugins → Repositories адрес ветки:

`https://github.com/zefut-creator/Premium-NFT-Finder/tree/sayplugin-v1`

Затем обнови список и установи **SayPlugin**. Если каталог не принимает ссылку на ветку, можно установить файл вручную из `plugins/sayplugin/sayplugin.plugin`.

## Настройка сокращений
Открой настройки SayPlugin и укажи по одной строке на сокращение:

```
;пр=Привет, как дела?
;спс=Спасибо!
;дата={date}
;время={time}
```

Напиши сокращение отдельным словом в сообщении — оно заменится перед отправкой.

## Совместимость
Плагин написан под публичный SDK exteraGram 1.4.4.3 и baseline приложения 12.5.1+. AyuGram основан на общей кодовой базе, но совместимость зависит от конкретной сборки. На твоём устройстве ещё требуется проверка.
