# Premium-NFT-Finder

Telegram-бот-каталог для участников, которые **добровольно** сообщают о наличии Telegram Premium и NFT-подарков.

## Возможности
- Регистрация через `/start`.
- Самостоятельное указание Premium и NFT.
- Поиск только среди зарегистрированных участников.
- Реферальные ссылки и подсчёт приглашений.
- Просмотр и удаление собственного профиля.
- Административная статистика через `/stats`.

## Важные ограничения
Telegram Bot API не позволяет боту просканировать всех пользователей Telegram или достоверно получить список их Premium/NFT-подарков. Поэтому статусы в каталоге указываются самими участниками и не являются независимой проверкой. Бот не собирает чужие контакты, не рассылает сообщения и не извлекает скрытые данные.

## Запуск
1. Установи Node.js 20 или новее.
2. Выполни `npm install`.
3. Задай переменную окружения `BOT_TOKEN` — токен от BotFather.
4. Необязательно: задай `ADMIN_ID` — свой числовой Telegram ID для команды `/stats`.
5. Запусти `npm start`.

База SQLite создаётся автоматически в файле `data.sqlite`. Для постоянного хранения на хостинге подключи persistent disk и задай `DB_PATH` на путь внутри него.

## Переменные окружения
- `BOT_TOKEN` — обязательно.
- `ADMIN_ID` — необязательно.
- `DB_PATH` — необязательно, по умолчанию `data.sqlite`.

## Безопасность
Не публикуй токен бота в репозитории, сообщениях или скриншотах. Если токен случайно раскрыт, перевыпусти его через BotFather.
